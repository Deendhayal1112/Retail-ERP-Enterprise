# Badge & Chip Components

Provides styling classes for visual labels, status indicators, and actionable tags.

## Classes

- `.badge`: Circular/pill metadata badge with semantic status layouts (Success, Danger, Warning, Info).
- `.chip`: Inline tag carrying action cues, label text, and optional icons.

## Examples

### Status Badges
```html
<span class="badge alert-success">Approved</span>
<span class="badge alert-danger">Declined</span>
<span class="badge alert-warning">Pending</span>
```

### Actionable Chip
```html
<div class="chip interact-button">
  <span>🏷️</span>
  <span>Retail Division</span>
</div>
```
