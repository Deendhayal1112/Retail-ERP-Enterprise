# Button Components

This folder contains the styling guidelines and structures for Buttons.

## Classes

- `.btn`: Standard button base style.
- `.btn-primary`: Primary color fill button.
- `.btn-secondary`: Light background button.
- `.btn-outline`: Transparent background border button.
- `.btn-danger`: Red color fill button.
- `.btn-icon`: Dynamic square aspect ratio icon wrapper button.

## States

- `:hover`: Subtle translation slide upwards.
- `:active`: Smooth scale down and depression transition.
- `:disabled`: Fade-out opacity lock.

## Example

```html
<button class="btn btn-primary interact-button">Primary Button</button>
<button class="btn btn-secondary interact-button" disabled>Disabled Button</button>
```
