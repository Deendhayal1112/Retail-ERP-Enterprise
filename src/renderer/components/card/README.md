# Card Components

This folder contains the styling guidelines for Card and Glass Card containers.

## Classes

- `.card`: Standard card wraps with border and base shadow.
- `.glass-card`: Glassmorphism-style semi-transparent background with background blur.

## Examples

### Standard Card
```html
<div class="card interact-card">
  <h3 class="text-card-title">Card Title</h3>
  <p class="text-body">This is card content.</p>
</div>
```

### Glass Card
```html
<div class="glass-card">
  <h3 class="text-card-title">Glass Card Title</h3>
  <p class="text-body">This is glass content.</p>
</div>
```
