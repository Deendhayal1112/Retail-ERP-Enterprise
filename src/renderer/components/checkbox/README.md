# Checkbox & Selector Components

This folder contains the styling guidelines for checkboxes, radio buttons, and toggle switches.

## Classes

- `.form-checkbox`: Checkbox style.
- `.form-radio`: Radio button style.
- `.form-toggle`: Toggle switch style.
- `.form-checkbox-label`, `.form-radio-label`, `.form-toggle-label`: Container alignments.

## Examples

### Checkbox
```html
<label class="form-checkbox-label">
  <input type="checkbox" class="form-checkbox" />
  <span class="text-body">Accept Terms</span>
</label>
```

### Radio Button
```html
<label class="form-radio-label">
  <input type="radio" name="options" class="form-radio" />
  <span class="text-body">Option 1</span>
</label>
```

### Toggle Switch
```html
<label class="form-toggle-label">
  <input type="checkbox" class="form-toggle" />
  <span class="text-body">Enable Features</span>
</label>
```
