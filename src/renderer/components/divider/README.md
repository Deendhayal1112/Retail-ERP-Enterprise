# Divider Components

This folder contains the styling guidelines for Divider components.

## Classes

- `.divider-horizontal`: Full-width horizontal divider with predefined top and bottom spacing variables.
- `.divider-vertical`: Full-height vertical partition divider.

## Examples

### Horizontal Divider
```html
<div class="divider-horizontal"></div>
```

### Vertical Divider
```html
<div style="display: flex; height: 40px;">
  <span>Item A</span>
  <div class="divider-vertical"></div>
  <span>Item B</span>
</div>
```
