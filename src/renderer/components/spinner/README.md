# Spinner & Loading Indicators

This folder contains spinner templates and overlays.

## Classes

- `.spinner`: Rotating loading loop.
- `.loading-overlay`: Modal mask container with blur to indicate page loading state.

## Examples

### Inline Spinner
```html
<span class="spinner" aria-label="Loading"></span>
```

### Loading Overlay
```html
<div class="loading-overlay">
  <span class="spinner"></span>
</div>
```
