# Tooltip Component

Provides a contextual text overlay that appears when the user hovers over an element.

## Classes

- `.tooltip-wrapper`: Relates the target parent container bounds.
- `.tooltip`: Faded popover overlay positioned relative to its `.tooltip-wrapper` container.

## Examples

```html
<div class="tooltip-wrapper">
  <button class="btn btn-secondary">Hover Me</button>
  <span class="tooltip">Action Details</span>
</div>
```
